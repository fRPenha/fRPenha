## Projetos selecionados

### [Nomos](https://github.com/fRPenha/nomos-sdd)

Camada local-first para descoberta, especificação e preparação de demandas antes da implementação.

Organiza contexto, regras, restrições, critérios de aceite, impacto técnico e tarefas, produzindo um pacote de execução para agentes como Codex, Claude Code e Gemini CLI.

`Python` · `Spec-Driven Development` · `Agentic Development`

### [DB Hydra MCP](https://github.com/fRPenha/DB-Hydra-MCP)

Servidor MCP para acesso controlado e somente leitura a múltiplos bancos de dados por meio de perfis nomeados.

Mantém credenciais fora do alcance dos agentes, aplica regras de segurança e permite consultas a diferentes bancos compatíveis com ODBC.

`TypeScript` · `MCP` · `ODBC` · `Docker`
